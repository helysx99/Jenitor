JENITOR

Free MIDI sequencer · macOS 14+ · Apple Silicon and Intel

Install

  1. Close your DAW. Extract the downloaded ZIP.
  2. Open the JENITOR installer package beside this guide.
  3. If macOS blocks it, open System Settings → Privacy & Security. After attempting to open the package, scroll down and choose Open Anyway, then confirm. Only approve a download you trust.
  4. Follow Installer's steps. It may ask for an administrator password. Choose Customize to select AU or VST3 formats.
  5. Restart your DAW and rescan plugins if necessary.

The package is unsigned. The plugin binaries have valid ad-hoc signatures, but no Apple-verified developer identity or notarization. macOS may require the approval above. Managed Macs may prohibit overrides.

Which plugin?

  • Logic Pro: JENITOR MFX in the MIDI FX slot of a software-instrument track.
  • Ableton Live: JENITOR VST3, routed to an instrument on another MIDI track.
  • Other hosts: JENITOR VST3 or the AU instrument, using the host's MIDI routing.

JENITOR outputs MIDI only. It includes no sound engine.

Installation locations

The installer installs for all users:

/Library/Audio/Plug-Ins/Components/JENITOR.component
/Library/Audio/Plug-Ins/Components/JENITOR MFX.component
/Library/Audio/Plug-Ins/VST3/JENITOR.vst3

If you previously installed copies under your home folder's Library/Audio/Plug-Ins, move those JENITOR copies elsewhere before installing. Two versions with the same plugin identity can confuse your DAW's scanner. Saved DAW projects are separate from these plugin bundles.

If the installed plugin is still blocked

First restart the DAW and rescan. If the host explicitly reports download quarantine, this optional command removes that attribute from only the three system-installed JENITOR bundles. It does not sign or notarize them:

sudo xattr -dr com.apple.quarantine \
  /Library/Audio/Plug-Ins/VST3/JENITOR.vst3 \
  /Library/Audio/Plug-Ins/Components/JENITOR.component \
  "/Library/Audio/Plug-Ins/Components/JENITOR MFX.component"

For manually installed copies in your home folder, use this instead; no sudo is normally needed:

xattr -dr com.apple.quarantine \
  "$HOME/Library/Audio/Plug-Ins/VST3/JENITOR.vst3" \
  "$HOME/Library/Audio/Plug-Ins/Components/JENITOR.component" \
  "$HOME/Library/Audio/Plug-Ins/Components/JENITOR MFX.component"

Run commands only for files from a source you trust. You do not need to disable Gatekeeper globally.

Uninstall

Close the DAW, then move the JENITOR bundles listed above to Trash. Also check the same folders under your home Library if you installed copies manually.
